## 4. 권한 사용 설명 (심사 시 물어보면)

- **RECORD_AUDIO(마이크)**: 어르신이 버튼을 눌러 시작하는 **음성 대화**에 사용. 사용자 조작으로만 시작하며 백그라운드 상시 녹음이 아닙니다.
- **POST_NOTIFICATIONS(알림)**: 복약·위급 알림.
- **ACCESS_COARSE_LOCATION(대략적 위치)**: 장소 지남력 채점·날씨 안내. 선택 권한(거부해도 정상 동작), 도시 수준만.
- **VIBRATE / WAKE_LOCK**: 알림 표시.

⚠️ **주의 — "상시 감시(관찰자)" 기능**: 등록된 목소리를 지켜보다 위급 시 알리는 베타 기능이 앱에 있습니다.

**정식 출시 첫 버전에서는 이 기능을 숨기거나(권장), 반드시 법률 자문 후 활성화**하시길 권합니다.

## 6. AAB 다시 빌드하는 방법 (버전 올릴 때)

코드를 고쳐 새 버전을 올릴 땐 **버전 숫자를 올린 뒤** 다시 빌드합니다.

1. `MaeumApp/android/app/build.gradle`에서
   - `versionCode` 를 +1 (예: 4 → 5)
   - `versionName` 을 올림 (예: "1.0.3" → "1.0.4")
2. 빌드:
   ```bash
   cd MaeumApp/android
   ./gradlew bundleRelease        # Windows: gradlew.bat bundleRelease
   ```
3. 결과물: `MaeumApp/android/app/build/outputs/bundle/release/app-release.aab`

> 서명은 `~/.gradle/gradle.properties`의 `MAEUM_UPLOAD_*` 속성으로 자동 적용됩니다.

## 8. 1.2.0 프로덕션 단계적 출시가 100%가 된 뒤 — Play 배포 스위치 켜기(로그인 화면 APK 링크 → Play)

> "공개"(심사 통과·출시 시작)만으로는 켜지 않습니다 — 단계적 출시 중엔 일부 사용자만 1.2.0을 받아, 나머지 1.0.3 사용자에게 받을 수 없는
> 업데이트를 안내하게 됩니다(2026-10-08 결정).

로그인 화면의 앱 받기는 **스위치 하나**(`NEXT_PUBLIC_APP_ON_PLAY=1`)로 바뀝니다(`lib/app-version.ts`). 켜면 함께 바뀌는 것:
- 로그인 화면 앱 받기: 웹 APK(1.0.3) → **Play 스토어** 링크(최신 v1.2.0)
- 휴대폰 등록 경고(`PUSH_TOKENS_LIVE`): 등록 휴대폰 0대를 경고하고, 운영자 "앱 알림 수신 기기 미확인" 경보를 켭니다

> 앱 안(웹뷰)에서는 스위치와 상관없이 **웹 APK 링크를 그리지 않습니다**(Play 정책 — Play 앱이 Play 밖에서 업데이트하게 하지 않는다).
