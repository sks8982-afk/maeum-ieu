## 3. 데이터 안전성 (Data safety) 설문 답변

Play Console → 앱 콘텐츠 → 데이터 안전성. 아래대로 답하세요.

**수집 항목 (Data types)**

|---|---|---|---|

| 사용자 ID·비밀번호 | 예 | 아니오 | 계정 관리 |
| 기타 개인정보(나이·성별) | 예 | 아니오 | 앱 기능 |
| 건강 정보 | 예 | 아니오 | 앱 기능(인지·마음 살핌) |
| 음성/오디오 | 예 | 예(Google) | 앱 기능(음성 인식) — ※원본 미저장 |
| 메시지(대화 내용) | 예 | 아니오 | 앱 기능 |

| 기타 개인정보(목소리 특징값·성문) | 예 | 아니오 | 앱 기능(상시 감시의 본인 목소리 확인) — 선택, 별도 동의, 암호화 저장 |

> 상시 감시를 켜면 어르신 목소리로 판단된 말소리도 같은 경로(Gemini)로 갑니다. "목소리 특징값"은 녹음이 아니라 기기에서 뽑은 숫자 256개입니다(2026-10-06 추가 — 개인정보처리방침 3항).
> "위치"는 도시 수준의 **대략적 위치(COARSE)** 만 사용하며, 거부해도 앱은 정상 동작합니다.

## 4. 권한 사용 설명 (심사 시 물어보면)

- **RECORD_AUDIO(마이크)**: 어르신이 버튼을 눌러 시작하는 **음성 대화**에 사용. 사용자 조작으로만 시작하며 백그라운드 상시 녹음이 아닙니다.
- **POST_NOTIFICATIONS(알림)**: 복약·위급 알림.
- **ACCESS_COARSE_LOCATION(대략적 위치)**: 장소 지남력 채점·날씨 안내. 선택 권한(거부해도 정상 동작), 도시 수준만.
- **VIBRATE / WAKE_LOCK**: 알림 표시.

⚠️ **주의 — "상시 감시(관찰자)" 기능**: 등록된 목소리를 지켜보다 위급 시 알리는 베타 기능이 앱에 있습니다.
Play는 백그라운드 오디오/녹음 기능을 엄격히 심사하고, 국내에서는 대화 녹음에 통신비밀보호법 이슈가 있을 수 있습니다.
**정식 출시 첫 버전에서는 이 기능을 숨기거나(권장), 반드시 법률 자문 후 활성화**하시길 권합니다.
(2026-10-06 정정: 홈 화면의 '상시 감시' 타일은 환경변수 없이 모든 어르신 계정에 보입니다. 대신 켜기 전에
목소리 등록 동의·상시 감시 동의(처리·보호자 제공)를 각각 받으며, 동의서·개인정보처리방침에 반영했습니다.
통신비밀보호법 판단(다른 사람과의 대화가 섞이는 경우)은 여전히 법률 자문 대상입니다.)

## 6. AAB 다시 빌드하는 방법 (버전 올릴 때)

코드를 고쳐 새 버전을 올릴 땐 **버전 숫자를 올린 뒤** 다시 빌드합니다.

1. `MaeumApp/android/app/build.gradle`에서
   - `versionCode` 를 +1 (예: 4 → 5)
   - `versionName` 을 올림 (예: "1.0.3" → "1.0.4")
2. 빌드:
   ```bash
   cd MaeumApp/android
   ./gradlew bundleRelease        # Windows: gradlew.bat bundleRelease
   ```
3. 결과물: `MaeumApp/android/app/build/outputs/bundle/release/app-release.aab`

> 서명은 `~/.gradle/gradle.properties`의 `MAEUM_UPLOAD_*` 속성으로 자동 적용됩니다.

## 7. Play Console 업로드 절차 (단계별)

1. **Play Console** → 앱 만들기 → 이름 "마음이음", 언어 한국어, 앱/무료, 선언 동의.
2. **앱 설정(대시보드의 '앱 설정 완료')**
   - 개인정보처리방침 URL: `https://maeum-ieu.vercel.app/privacy`
   - 앱 액세스 권한: **로그인 필요** → 심사용 테스트 계정 제공
     - 이메일 `test1234@test.com` / 비밀번호 `demo1234` (어르신 데모 계정, 이미 준비됨)
   - 광고: 없음 / 콘텐츠 등급 설문 작성 / 타겟층: 성인
   - 데이터 안전성: 위 3번대로 작성
3. **스토어 등록정보(기본)**
   - 짧은 설명·자세한 설명: 위 2번 복사
   - 앱 아이콘: `icon-512.png`
   - 피처 그래픽: `feature-graphic-1024x500.png`
   - 휴대전화 스크린샷: `screenshots/` 3장 업로드
4. **프로덕션 → 새 버전 만들기**
   - Play 앱 서명: 켜기(기본)
   - App bundle 업로드: `app-release.aab`
   - 출시명/변경사항(릴리스 노트) 작성 → 저장 → 검토 → **프로덕션 출시**
5. 심사 대기(보통 수 시간~수일). 승인되면 게시됩니다.
